# **App Name**: SEDS Pakistan Digital Hub

## Core Features:

- Homepage Hero Section: Visually striking introduction with animated stars and calls to action, blending historical trust with futuristic ambition.
- About Astronautics Section: Informative section with a 3D rotating satellite illustration, explaining the science and technology of space travel and exploration.
- What SEDS Does Timeline: Dynamic timeline showcasing SEDS Pakistan's activities, including workshops, ground stations, and hackathons, using neon headings for emphasis.
- Skills & Workshops Grid: Responsive grid layout displaying various skills and workshops offered, with interactive card styles.
- Projects Masonry Grid: Masonry grid of project cards with hover video previews, providing an engaging showcase of SEDS Pakistan's initiatives.
- Join Us Form: Interactive form for prospective members, with data saved to Firestore and automated welcome emails triggered upon submission.

## Style Guidelines:

- Primary color: Sunset Red (#FF6B5A) to evoke energy and passion for space.
- Background color: Deep Black (#0B0C10) to create a cosmic, immersive environment with a desaturated space theme.
- Accent color: Space Blue (#5A9BD5) for interactive elements and highlights, drawing the user's eye to important details.
- Headline font: 'Bebas Neue' sans-serif for an uppercase, high-impact, modern feel.
- Body font: 'Courier Prime' monospace for historical trust and technical readability. Note: currently only Google Fonts are supported.
- Accent font: 'Orbitron' sans-serif for neon hover effects on links/buttons, creating a futuristic ambiance. Note: currently only Google Fonts are supported.
- Animated rocket/satellite icons floating in the footer to enhance the cosmic theme.
- Parallax scrolling effects to give the planets/stars in the background a sense of depth.
- Page transitions using Framer Motion (fade + slide) for smooth navigation between sections.
