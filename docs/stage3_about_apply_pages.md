## 📖 Page: About SEDS Pakistan (`/about`)

**Visibility:** Public.  
**Purpose:** Institutional credibility and network visualization.

### Interactive Sections

2. **Chapter Network Map:** Visual listing of all university chapters (LUMS, IST, NUST, etc.) with their respective presidents.
3. **Timeline:** Interactive scroll through the organization's history since founding.
4. **Advisory Board:** Profiles of senior mentors and industry experts.

## 📝 Page: Apply for Membership (`/apply`)

**Visibility:** Public. (Sign-in required to submit).  
**Purpose:** Central gateway for all national recruitment drives.

### The Application Form
- **Personal Info:** Contact details, university, education.
- **Motivation:** "Why SEDS?" "What technical value do you bring?"
- **Team Interest:** Multiple choice selection for technical committees.
- **Agreement:** Policy and code of conduct sign-off.

---

## 📬 Processing Applications (`/admin/submissions`)

**Access:** HR Director + Leadership.

- **The Inbox:** All applications are queued in a real-time list.
- **Review Drawer:** Admin sees full form answers + user profile link.
- **Actions:**
  - **Shortlist:** Moves to shortlisted stage; notification sent.
  - **Invite:** Triggers official email with invite link token.
  - **Reject:** Sends structured feedback email to applicant.
